# План виправлення дизайну

Що зламано — [design-audit.md](design-audit.md). Ціль — [design-system.md](design-system.md).

Порядок обрано так, щоб спершу закрити нечитабельне (етап 1 — точкові зміни, без редизайну), потім закласти токени (етап 2), і лише після цього перебудовувати екрани (етапи 3–6). Кожен етап — окремий PR.

Розмір: **S** — кілька файлів, **M** — один модуль, **L** — перебудова екрана.
